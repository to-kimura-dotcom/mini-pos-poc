# ミニPOS 17時メール版 PoC

公開デモの会計をGoogleスプレッドシートに共通保存し、毎日17時台の最初の定期実行で `nacchanngogogo@gmail.com` に集計メールを送る学習用アプリです。メールには売上合計、会計件数、客単価、商品別販売数・売上額を含みます。17時以降の会計はその日の17時レポートには入りません。

## セットアップ

1. Googleアカウントで [Apps Script](https://script.google.com/) の「新しいプロジェクト」を作る。
2. 初期の `コード.gs` の内容を、このフォルダの `Code.gs` 全文に置き換える。
3. 左の「＋」から「HTML」を追加し、名前を **Index** にする。生成された内容を `Index.html` 全文に置き換える。Apps Script上ではファイル名が `Index.html` と表示される。
4. 「プロジェクトの設定」で「appsscript.json マニフェスト ファイルをエディタで表示する」を有効にし、`appsscript.json` の内容を同名ファイルに貼る。タイムゾーンは `Asia/Tokyo`。
5. 保存後、関数の選択欄で **setup** を選んで「実行」。Googleの権限確認でスプレッドシート作成・メール送信・トリガー作成を許可する。setup は商品10点の入ったスプレッドシートを作り、1分間隔の定期トリガーを登録する。再実行しても商品やトリガーを重複作成しない。
6. 右上「デプロイ」→「新しいデプロイ」→種類を「ウェブアプリ」。**次のユーザーとして実行：自分**、**アクセスできるユーザー：全員** を選び、デプロイする。発行された `/exec` のURLが共通データ版のURL。
7. URLを開き、テスト会計を1件行い、売上集計に同じ数字が出ることを確認する。別のブラウザでも同じ売上が見えることを確認する。

## メール送信

- `sendReportIfDue` は毎分動きますが、日本時間の17時台かつ当日未送信の場合だけ送信します。初回の実行で送信するため、17:00ぴったりの配達を保証するものではありません。
- 送信先は `Code.gs` 冒頭の `REPORT_TO` です。差出人はセットアップしたGoogleアカウントです。
- 送信成功後に日付を記録して、その日の重複送信を防ぎます。失敗した場合は次の実行で再試行します。
- 動作確認は当日の17時に試験会計を入れてメールを確認します。事前に送信テストをする場合は、管理者だけが `sendReportIfDue` を直接実行しても17時以外は送信されません。テスト用に時刻条件を一時変更する際は、送信先と日付記録に注意してください。

## 現在のGitHub Pages URLについて

既存の `https://to-kimura-dotcom.github.io/mini-pos-poc/` は、アップロード済みの旧版のままです。共通データ版はApps Scriptの新しいURLで動きます。新URLが動作したら、そのURLを共有するか、GitHubの `index.html` を新URLへの案内ページに差し替えてください。**旧版でブラウザに保存した売上は自動移行されません。**

## 公開PoCの制約

「全員」に公開すると、URLを知る人は商品を変更し、架空の会計を登録できます。認証や権限管理は未実装です。実売上、個人情報、決済情報を扱わないでください。スプレッドシートの共有設定は公開しないでください。Apps Script・Sheets・MailAppの利用上限に達すると保存や送信が止まる場合があります。
